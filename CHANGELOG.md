# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2026-05-07

### Added
- **Studio Dashboard**: Interactive console for real-time engine configuration.
- **SVG Export**: Support for static and CSS-animated SVG generation for GitHub READMEs.
- **New Options**: Added `columns`, `scrollable`, `showLabels`, and `showLegend` props.

### Improved
- **Performance**: 90% faster export engine and optimized grid rendering.
- **UX/A11y**: Enhanced ARIA support and fixed SVG rendering across browsers.

## [1.0.2] - 2026-05-04

### Fixed
- Added a README video preview for GitHub and NPM.

## [1.0.1] - 2026-05-04

### Fixed
- Fixed GitHub Release permissions in CI/CD pipeline.

## [1.0.0] - 2026-05-04

### Added
- Initial release of `react-github-snake`.
- Interactive GitHub contribution heatmap transformed into a playable snake game.
- Smart pathfinding engine for automated gameplay (Automode).
- Responsive grid system that fits any container width.
- Support for GitHub Light and Dark themes.
- Sound effects using Web Audio API.
- Zero-dependency architecture with full TypeScript support.
- Comprehensive documentation and interactive demo site.
