## [1.0.2] - 2026-05-04

## [1.0.1] - 2026-05-04
### Fixed
- Fixed GitHub Release permissions in CI/CD pipeline.

## [1.0.0] - 2026-05-04

### Added
- Initial release of `react-github-snake`.
- Interactive GitHub contribution heatmap transformed into a playable snake game.
- Smart pathfinding engine for automated gameplay (Automode).
- Responsive grid system that fits any container width.
- Support for GitHub Light and Dark themes.
- Sound effects using Web Audio API.
- Zero-dependency architecture with full TypeScript support.
- Comprehensive documentation and interactive demo site.
